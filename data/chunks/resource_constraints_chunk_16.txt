r modifies the settings for
the container's cgroup on the host machine.
Option
Description
--cpus=<value>
Specify how much of the available CPU resources a container can use. For instance, if the host machine has two CPUs and you set
--cpus="1.5"
, the container is guaranteed at most one and a half of the CPUs. This is the equivalent of setting
--cpu-period="100000"
and
--cpu-quota="150000"
.
--cpu-period=<value>
Specify the CPU CFS scheduler period, which is used alongside
--cpu-quota
. Default
