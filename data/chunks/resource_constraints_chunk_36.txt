 default, if an out-of-memory (OOM) error occurs, the kernel kills processes in a container. To change this behavior, use the
--oom-kill-disable
option. Only disable the OOM killer on containers where you have also set the
-m/--memory
option. If the
-m
flag isn't set, the host can run out of memory and the kernel may need to kill the host system's processes to free memory.
For more information about cgroups and memory in general, see the documentation
for
Memory Resource Controller
.
