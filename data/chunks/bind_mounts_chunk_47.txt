The
--mount
and
-v
examples have the same result.
--mount
-v
$
docker run -d
\
-it \
--name devtest \
--mount type=bind,source="$(pwd)"/target,target=/app,readonly \
nginx:latest
$
docker run -d
\
-it \
--name devtest \
-v "$(pwd)"/target:/app:ro \
nginx:latest

docker inspect devtest

correctly. Look for the
Mounts
