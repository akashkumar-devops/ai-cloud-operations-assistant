Running
docker compose up
for the first time creates a volume. Docker reuses the same volume when you run the command subsequently.
You can create a volume directly outside of Compose using
docker volume create
and
then reference it inside
compose.yaml
as follows:
services
:
frontend
:
image
:
node:lts
volumes
:
-
myapp:/home/node/app
volumes
:
myapp
:
external
:
true
