CPU period constraint
The default CPU CFS (Completely Fair Scheduler) period is 100ms. We can use
--cpu-period
to set the period of CPUs to limit the container's CPU usage.
And usually
--cpu-period
should work with
--cpu-quota
.
Examples:
$
docker run -it --cpu-period
=
50000
--cpu-quota
=
25000
