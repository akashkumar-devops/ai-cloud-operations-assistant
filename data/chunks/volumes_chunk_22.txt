container uses its own
local volume. None of the containers can share this data if you use the
local

The following example starts an
nginx
service with four replicas, each of which
uses a local volume called
myvol2
.
$
docker service create -d
\
--replicas=4 \
--name devtest-service \
--mount source=myvol2,target=/app \
nginx:latest
Use
docker service ps devtest-service
to verify that the service is running:
$
docker service
