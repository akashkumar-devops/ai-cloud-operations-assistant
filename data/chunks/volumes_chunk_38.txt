Create a service which creates an NFS volume
The following example shows how you can create an NFS volume when creating a service.
It uses
10.0.0.10
as the NFS server and
/var/docker-nfs
as the exported directory on the NFS server.
Note that the volume driver specified is
local
.
NFSv3
$
docker service create -d
\
--name nfs-service \
--mount 'type=volume,source=nfsvolume,target=/app,volume-driver=local,volume-op
